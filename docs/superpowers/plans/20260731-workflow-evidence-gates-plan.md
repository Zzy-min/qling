# 轻灵流程证据门禁与运行状态收口实施计划

1. **RED：提示词门禁**
   - 扩展 OpenCLI/工作流单测，要求证据分层、同轮直接证据、只读预检、声明证据映射和删除授权。
   - 构建后运行定向测试，确认旧实现不能满足新增断言。

2. **RED：恢复终态**
   - 为 `RecoveryController` 增加成功清除及失败、取消收口的期望测试。
   - 为 `runOuterAgentLoop` 增加成功返回后恢复状态为空的集成断言。

3. **GREEN：最小实现**
   - 在基座工作流中加入可执行的证据门禁和 OpenCLI 当前状态预检规则。
   - 在恢复控制器增加终态收口方法，并在外层循环所有非暂停出口调用。
   - 保持暂停/恢复、审批、Agent 和工具调用接口兼容。

4. **验证与复查**
   - 串行运行定向测试、构建、完整 `ci:check`、`git diff --check`。
   - 检查工作树，确认没有覆盖已有 Dashboard/TUI 改动。
   - 在 `docs/superpowers/reviews/` 记录测试证据、已知限制和未执行的外部动作。
