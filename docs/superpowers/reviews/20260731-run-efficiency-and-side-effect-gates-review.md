# 轻灵运行效率与副作用门禁复查

## 结论

实现符合规格，可以进入后续真实任务观察阶段。运行时现在同时具备提示词去重、同类失败熔断、总失败预算、自动压缩节流和文件副作用账本；未改变工具业务协议、审批入口或经典/全屏 TUI 输出接口。

## 实现核对

- 强制规则完整正文只保留在 system 的【强制规则】section；dynamic context 使用带摘要指纹的短引用。
- `RunEfficiencyGuard` 默认在同类失败第2次、总工具失败第8次暂停。
- 失败指纹包含工具、类别、代码和归一化错误内容；路径、数字等易变噪声不用于绕过门禁，不同错误内容仍保持区分。
- 自动压缩按尝试计数：每次运行最多2次，两次至少间隔4个 Agent turn；失败时沿用原有本轮抑制机制。
- 成功 `write` / `patch` 记录规范化绝对路径和创建/更新类型，去重后在下一模型轮注入，并被压缩器确定性保留。
- 守卫暂停会保留已经产生的工具结果和副作用账本，并进入现有 `/recover` 流程。

## 基线对比

- 旧任务基线：453 秒、35 attempts、48 次工具启动、20 次失败、12 次压缩、296024 session tokens。
- 当前本机规则集合为 2701 字符：
  - 旧结构等价注入 3 份，共 8103 字符。
  - 新结构为 1 份正文加 112 字符引用，共 2813 字符。
  - 规则层结构字符量减少 65.3%。
- 确定性主循环回归证明：即使命令参数变化，同类失败也在第2次后暂停；成功文件变更会在下一模型轮可见。
- 真实端到端耗时与 token 改善需由后续同类真实任务对照确认，当前不把结构测量误报为线上性能结果。
