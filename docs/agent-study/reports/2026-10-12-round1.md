## 1. Agent loop + 上下文压缩/预算

### Grok Build
- `crates/codegen/xai-grok-agent/src/compaction.rs` `CompactionPolicy`：`auto_compact_threshold_percent=85`、`wall_clock_budget_secs=300`（单次压缩墙钟预算，超时截断重试）、`memory_flush_enabled`（压缩前先跑一次记忆 flush）、`two_pass_enabled`（接近阈值时后台预先摘要早期历史，压缩时再与尾部合并）。
- `crates/codegen/xai-chat-state/src/compaction_utils.rs`：
  - `prepare_conversation_for_summarization` 剥离工具消息/推理块/图片后再摘要；`prepare_conversation_for_verbatim_summarization` 为保持 prompt cache 前缀对齐保留原文。
  - `truncate_trailing_incomplete_tool_call`：丢掉末尾无结果的 assistant tool_calls。
  - `fit_conversation_to_budget` + `recover_truncated_tail_unit`：从尾部按整轮保留，工具 run 不拆开；最后一轮放不下时**原地截断**而非丢弃（带 `[... truncated N bytes ...]` 标记）。
  - `validate_compacted_history` / `sanitize_compacted_history` / `repair_history` / `strip_displaced_tool_results`：去重 ToolResult、剥离孤儿/错位 ToolResult、为未应答 tool_call 补合成结果；纯函数、幂等，返回 `HistoryRepairReport`。
  - `is_degenerate_summary`（`MIN_SUMMARY_SEED_CHARS=500`）、`AUTO_CONTINUE_PROMPT`、`CompactionStateContext`（压缩时把 todo/子 agent/后台任务/工作流状态注入摘要）。
- `crates/codegen/xai-chat-state/src/compaction_mode.rs` `CompactionMode`（含 segments 模式）；`xai-compaction-transcript/` 把压缩前完整转录落盘并在摘要中给出位置提示（`format_transcript_location`）。
- `xai-chat-state/src/image_budget.rs` 图片预算单独管理。

### qling 现状
- `src/agent-loop.ts`（1423 行）+ `src/agent/main-loop.ts`、`src/agent/tool-orchestrator.ts`（`repairToolArguments`，修参数而非修历史）。
- `src/context-budget.ts` `resolveContextBudget`：window×ratio(0.5–0.95，默认 0.85)，否则 legacy 6000。
- `src/context-compactor.ts` `ContextCompactor.compactDetailed`：保护最近 recentKeep 条并向外扩展 tool chain（`findLinkedAssistantIndex`）；冲突检测/投毒扫描；代码骨架化（`skeletonizeMessages`）；LLM 摘要 + `buildLocalFallbackSummary`；`maxSummaryAttempts`（`QLING_COMPACTION_MAX_ATTEMPTS`，默认 3）。
- `src/context-tool-hygiene.ts` `summarizeToolOutputForContext`：头尾截断 + 中文标记。
- 未发现：发送前的历史配对修复（rg `repair|sanitize|orphan` 在 agent-loop/llm-client 中无此类逻辑）；跨轮次的压缩失败熔断（rg `consecutive|circuit|熔断` 无结果）；压缩前转录落盘；压缩前记忆 flush。

### 书本清单
- §2.3.4 缓存作为架构约束：动态内容应置于缓存边界之后、工具结果替换字符串"首次出现即冻结"。qling `src/agent/system-prompt.ts:68` 把 `platform=` 写进系统提示（静态，OK）；但 `summarizeToolOutputForContext` 按当前 maxChars 每次重新计算——若配置/预算变化会改变前缀，**部分遵循**。
- §2.7.4 分层压缩：①工具结果预算✔（hygiene）②噪声删除～（骨架化）③API 微压缩✘ ④归档式逐轮摘要✘ ⑤全量压缩✔，但**缺"连续失败熔断器"**✘。
- §2.7.5 "压缩最易丢失早期决策/失败路径，需落文档"：qling 有 todo/plan 模块，但压缩摘要未系统注入任务状态（对比 Grok `CompactionStateContext`）。

### 可借鉴（收益/成本排序）
1. **发送前历史修复 `repairHistory`**（高/低）：移植 `repair_history` 三步语义。直接减少 provider 400 和"tool_use_id 不匹配"导致的整轮失败。→ Brief 01
2. **压缩熔断 + 退化摘要检测**（高/低）：会话级连续失败计数，N 次后停用自动压缩并改走本地 fallback；摘要过短视为失败（`is_degenerate_summary`）。→ Brief 01
3. **尾部原地截断而非整轮丢弃**（中/低）：`fit_conversation_to_budget` 思路用于 recent 区超预算时。
4. **压缩摘要注入任务状态 + 转录落盘路径**（中/中）：参照 `CompactionStateContext` / `xai-compaction-transcript`。
5. 两阶段后台预摘要（中/高，round 2+）。

## 2. 工具分发、沙箱、权限审批

### Grok Build
- 注册/分发：`xai-grok-tools/src/registry/mod.rs`、`crates/common/xai-tool-runtime/src/dispatch.rs`、`xai-grok-shell/src/session/acp_session_impl/tool_dispatch.rs`。
- 权限规则：`xai-grok-config-types/src/permission.rs` `PermissionRule{action, tool, pattern, pattern_mode(Glob|Domain)}`，`RuleAction` **默认 Deny**（注释引 CWE-1188：漏写 action 不得变成全放行）；`ToolFilter` 未知值反序列化报错。

- 输出截断：`xai-grok-tools/src/util/truncate.rs`、`mcp_truncate.rs`。

### qling 现状
- `src/tools/index.ts` 注册；`src/tools/bash.ts` `runBash`，`dangerousPatterns`（`rm -rf /`、fork bomb、mkfs…）；`src/pipeline/hooks.ts:139` `matchDangerousPatterns` 对**整条命令字符串**做 `new RegExp(p).test(cmd)`（字符串模式会被当正则，如 `"rm -rf /*"` 中 `*` 语义变化）。
- `src/guard/permissions.ts` `PermissionMatrix.evaluate(toolName)`：**仅按工具名**glob 匹配，无参数/命令模式；默认 decision `"allow"`。
- `src/guard/approval.ts` `ApprovalGate`；`src/guard/permission-grants.ts` `PermissionGrantStore`（scope 仅 session）；`src/runtime/sandbox-profile.ts`（cwd 范围检查，bash.ts:152-158）；`src/guard.ts` URL 策略、脱敏、审计。

### 书本清单
- §1.2.5 多层护栏 + 测"误拒绝"：qling 有上下文层（content-filter）与执行层（审批），数据层仅 cwd profile；**缺允许用例回归测试**的说法需 Pi 核实。
- §4.6 执行工具 / §5.1.4 Harness 实践：危险命令需结构化判断——qling 字符串正则易被 `bash -c`、`sudo`、`&&` 拼接绕过。

### 可借鉴
1. **命令分段 + 去包装后逐段判定**（高/中）：TS 实现轻量 shell 分词（引号/`&&||;|`/`$(...)` 检测，遇复杂语法降级为 ask），每段 `unwrap`（sudo/env/timeout/nice/xargs）后匹配危险规则与 allow 规则。→ Brief 02
2. **PermissionRule 增加 `pattern`（参数匹配，如 `bash(git status*)`、`url_fetch(domain:x.com)`）且缺省 action=deny**（高/中）。→ Brief 02
3. **授权不能"宽脚本匹配窄授权"**（中/低）：session grant 仅在整条命令就是单段时复用。
4. 环境变量风险表（中/低）：qling bash 已有 `env_inject` 键名校验，可追加 `LD_PRELOAD/DYLD_*/NODE_OPTIONS/GIT_SSH_COMMAND` 等禁注入名单。
5. OS 级沙箱（seatbelt/landlock）（高/高，round 2+；可参考 codex `codex-rs/linux-sandbox`）。
